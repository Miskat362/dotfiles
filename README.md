# 🌌 My Customized EndeavourOS Dotfiles

Welcome to my personal dotfiles repository! This is a complete backup of my highly customized, modern, and fluid Linux desktop environment, tailored for daily development and productivity.

## 💻 System Overview
- **OS:** EndeavourOS (Arch-based)
- **Shell Theme/Config:** ilyamiro/serpantinum shell
- **Terminal Emulator:** Kitty Terminal & VS Code Integrated Terminal
- **Shell:** Zsh (Z Shell) with Starship Prompt

---

## 🎨 Key Features & Customizations

### 🚀 1. Starship Prompt & FiraCode Font
- Styled with the beautiful, color-coded **Pastel Powerline** preset.
- Uses **FiraCode Nerd Font** for clean, modern coding ligatures (`->`, `==`) and rich icon rendering.
- Full **GitHub/Git integration** directly in the prompt (displays active branch name, modification symbols, and sync status).

### ⚡ 2. Advanced Zsh Experience
- **Auto-suggestions:** Faded text predictions based on history (press `Right Arrow` to autocomplete).
- **Syntax Highlighting:** Instant visual feedback (Green for valid commands, Red for errors).
- **Auto-Directory Content Show:** Simply typing a folder's name automatically navigates into it (`cd`) and triggers a stylized list of its contents (`eza/ls`) with file icons.

### 🖼️ 3. Dynamic Live Wallpapers & Matugen
- Background running custom looped `.mp4` anime/live video wallpaper via `mpvpaper` mapped to monitor `eDP-1`.
- Fully integrated with **Matugen Theme Engine** — changing the wallpaper automatically recalibrates the system's accents, bar colors, and borders to perfectly match the background palette.

### 📊 4. Customized Fastfetch
- Configured a personalized dual-box architecture separating **Hardware Information** (Host, CPU, GPU, RAM, Disk) and **Software Information** (OS, Kernel, Shell, Packages, Uptime).
